# R2Kernel™ 1.0.0rc5

!!! note "Prerelease archive"

    These are the notes of a 1.0.0 prerelease as published, kept for reference.
    They are not the current release. See [Releases](index.md) for the current
    release and its support, installation and limitation contract.

RC5 is an archived prerelease, not the current supported evaluation version.
Its published artifacts and tags are immutable. Use the
[current release notes](index.md) for current support and upgrade limits.

## Observable changes

- Package replacement validates the replacement before committing it and retains
  recovery information on failure. Resource access rejects stale or unauthorized
  identities.
- Network inputs, generic decoding and deferred work have resource bounds.
  Federation rejects incompatible or unauthenticated sources without stopping
  compatible topics.
- Python Control connection handling and readiness reporting improve without
  automatically replaying a failed application call.
- Runtime graph counters distinguish receipt, completion, failure and overruns.
  Protocol completion is not handler acknowledgement or physical completion.
- Installer validation checks SDK payloads before service cutover. Tutorial
  transport rejection and failed safe-off acknowledgements are reported rather
  than treated as success; safe-off and watchdog obligations are unchanged.

## Qualification and unresolved limitations

The 1 ms / 1 kHz acceptance requirement was not satisfied. RC5 does not qualify
physical-device or hard-real-time performance, and the cause of every missed
deadline was not isolated.

An intermittent incinerator command failure has no confirmed root cause or
resolution. Additional diagnostics and collections without the failure are
not proof that the defect was resolved.
