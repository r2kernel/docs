# Contributing To R2Kernel

Public contributions focus on SDKs, application-facing specs, tutorials,
and documentation. The proprietary runtime source is not part of the public
contribution surface. Use [R2Kernel Issues](https://github.com/r2kernel/r2kernel/issues)
for all bugs, feature requests, usage questions, and documentation feedback.
The SDK and documentation repositories share this tracker.

For SDK and spec changes, use [r2kernel/sdk](https://github.com/r2kernel/sdk)
and identify the affected contract ID and version. Documentation source is in
[r2kernel/docs](https://github.com/r2kernel/docs).

## Useful Feedback

- Explain the application or component requirement and current behavior.
- Include a minimal public reproducer and the runtime/SDK versions used.
- For spec proposals, describe compatibility, units, frames, timing, errors,
  cancellation, and migration effects where relevant.
- Distinguish a proposed contract from a released guarantee. An issue or pull
  request alone does not make a spec stable or supported.

Do not submit private implementation details, customer data, credentials, or
material that you are not authorized to share. Do not report security issues
or vulnerabilities in a public issue, pull request or discussion; report them
privately as described in [SECURITY.md](SECURITY.md).
